## 1. 项目概览

**完整名称**：夜夜班的进制转换练习 Sites版

这是一个面向中职/高职单片机课堂的静态教学网站，围绕“进制转换 → 8051 端口理解 → 开发板实操 → 竞赛练习”组织内容。它把二进制、十进制、十六进制学习，STC89C52RC/TX-1C 开发板的 P1 LED 仿真，Keil C51 教程，以及带账号和离线成绩的进制竞技场放在一个入口中。

项目解决的问题是：学生通常需要在多个讲义、Keil、开发板说明和练习页面之间来回切换，难以把数值、端口电平、C 代码和实物引脚联系起来。本项目提供一个课堂演示和练习入口，但不替代 Keil、STC-ISP 或真实开发板。

### 适用场景和目标用户

- 教师：课堂讲解进制、P1 端口、LED/按键/蜂鸣器和 Keil 操作。
- 学生：完成进制转换题、观察端口仿真、阅读 C51 示例并参加进制竞速。
- 项目维护者：继续扩展教学模块、接入真实编译工具链和成绩服务。

## 3. 当前完整功能

保留进制学习、P1 LED 仿真、课堂 C51 代码、延迟函数说明、TX-1C 矢量开发板与 Keil 教程。

### 8421 拼数小花园（2026-10-07）

- 给出 0～15 的十进制题目，选择 8、4、2、1 卡片相加；选中为 1，未选中为 0。
- 实时显示加法式与四位二进制，提交后检查答案；0 对应全部不选。
- 自由练习与 60 秒挑战，每轮覆盖全部 16 个数字后重新洗牌。
- 可取消选择、清空、提示；首次答对收获花朵，提示题不计花朵。
- 键盘 8/4/2/1 切换卡片，Enter 检查或下一题。
- 只使用 Local Storage 保存本机累计花朵，不需要登录、数据库、排名或联网。


## 4. 技术栈和运行环境

- 原生 HTML、CSS、JavaScript，单页入口，无 `package.json`、npm 构建系统或框架。


- Python 标准库 HTTP 服务 `compiler_bridge.py`，调用 Keil C51 的 `C51.exe`、`BL51.exe`、`OHX51.exe`。
- Cloudflare Sites 静态发布，`.openai/hosting.json` 当前指定 `dist` 为发布目录。
- 本地开发环境需要 Windows、Python；真实编译桥还需要安装 Keil C51 和对应头文件。

## 6. 本地启动、构建、测试和部署

### 启动

项目没有 npm 安装或构建命令。可以直接打开 `index.html`；为了让资源、IndexedDB 和浏览器权限表现更稳定，建议在项目根目录运行：

```powershell
python -m http.server 8765
```

访问 `http://127.0.0.1:8765/`。

### 构建/同步

根目录 `index.html` 是开发文件，发布前需要同步到 `dist/index.html`，并同步新增或修改的 `assets` 文件：

```powershell
Copy-Item .\index.html .\dist\index.html -Force
```

`finish_vector.py` 的无参数模式还会导出开发板 SVG 并执行 JavaScript 语法检查；`publish` 模式会读取隐藏输入的 Sites 凭据、推送源码并打包 `dist`，不要把凭据写入仓库。

### 测试和检查

- 用 Node.js 对 `index.html` 的内联脚本执行语法解析。
- 比较 `index.html` 与 `dist/index.html` 的 SHA-256，确认发布副本同步。
- 用浏览器逐页检查登录、竞技场、代码编辑和开发板交互。
- 本地编译桥启动命令：`python .\compiler_bridge.py`；服务仅监听 `127.0.0.1:8766`。
